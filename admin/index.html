Token salvo neste navegador.
Como criar o token
  1. No GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Em Repository access, escolha Only select repositories e marque só baixougame.
  3. Em Permissions → Repository permissions, coloque Actions: Read and write (nada além disso).
  4. Defina uma validade (por exemplo, 90 dias), gere e cole aqui.

O token fica só no seu navegador e só é enviado ao GitHub. Não use em computador compartilhado.
